# Academic website

- Keep this a lightweight static HTML/CSS/JS site. Do not add frameworks, generators, a CMS, or a database unless explicitly requested.
- Preserve the restrained academic identity: Georgia headings, sans-serif body, dark blue accent, generous whitespace, thin dividers, existing widths and responsive navigation. Reuse `styles.css` patterns.
- Read all relevant project materials before writing a detail page: briefs, completed papers, slides, figures, code, and data documentation. Synthesize a research narrative rather than converting a source document or preserving assignment questions.
- Propose 2–4 accurate academic title options before choosing one. Foreground the substantive question; avoid course numbers and assignment-style titles or URLs.
- Use research titles, meaningful muted subtitles, substantive prose, and selected figures to communicate academic identity. Do not add decorative category/uppercase eyebrows, year–topic–method strings, assignment/coursework labels, badges, or role/status/context metadata grids unless explicitly requested. Detail headers flow from Back to Projects to title, subtitle, introduction, and section navigation. Keep subtitles clearly subordinate to titles.
- Preserve the two-column homepage selection and text-with-figure overview layout where suitable, with overview figures on the right. Left-align detail-page images with the prose and captions, cap their inline width at roughly 480px, preserve aspect ratio without cropping, and retain readable captions and full-size links. Keep images responsive on narrow screens.
- Prefer neutral academic prose or occasional accurate first-person singular language. Do not imply collaborative authorship with “we,” “our,” “team,” or “collaborative” unless sources establish it and the user explicitly presents it that way on the website. Do not infer sole authorship from a portfolio placement; flag ambiguous contributions privately.
- Never invent findings, methods, datasets, roles, publication status, or contributions. Distinguish completed from proposed work, and descriptive, predictive, correlational, and causal claims. Resolve conflicting versions privately using the strongest supported result, or omit an uncertain number. Keep only substantive limitations in public prose; do not narrate file consultation, source reconciliation, or webpage construction.
- `Project-Materials` and other private research repositories are read-only sources; do not modify their files. Do not copy private papers, slides, code, notes, datasets, or images into this website unless already approved or clearly intended for public website use. Preserve figure axes, scientific meaning, useful captions, and alt text. Keep sensitive editorial notes outside this repository and read-only source directories.
- Research Interests remains on the homepage. Keep the approved four selections: Exclusionary Populism, Migration and Education, Upward Mobility, and Constitutional Echoes. The complete collection and all detail pages are authorized; adapt each page's editorial structure to the project.
- Use depth-relative links for pages, CSS, images, and the existing CV. Support both the GitHub Pages project prefix and a future custom-domain root. Never create links to unbuilt detail pages.
- Check links/fragments/assets, heading order, duplicate IDs, keyboard focus, reduced motion, no-JavaScript reading, mobile navigation, figure/table readability, console errors, and common viewport widths. Verify both root and project-prefix hosting before delivery.
- Preserve unrelated local changes. Keep hosting settings unchanged unless deployment is explicitly requested; verify the GitHub Pages source before an authorized deployment.

- Preserve the approved project titles and visual system during content revisions. Build a private visual/source inventory first; generally use 3–5 meaningful original research figures per detail page when sources support them, placing each near its interpretation. Redraw only explicit numerical results without new analysis. Keep the original migration DiD, matching balance, constitutional clustering/history, and Brown citation figures.
- Introduce every identifiable dataset before sample/preprocessing details: producer, coverage, unit, analytical subset, and relevance. Link its authoritative landing page; privately flag unknown provenance. CFPS must link to `https://www.isss.pku.edu.cn/cfps/en/index.htm`.
- The Projects overview must contain exactly: “They include conference research and coursework projects developed during my study.” Research endings should conclude with interpretation or a substantive limitation.
